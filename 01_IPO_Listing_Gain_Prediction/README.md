# IPO Listing Gain Prediction

## Business Problem

Investors often rely on Grey Market Premium (GMP), subscription levels, or media hype to decide whether to apply for an IPO. However, these signals are frequently interpreted in isolation, leading to inconsistent investment decisions.

This project develops a multivariate regression model to identify which pre-listing indicators genuinely predict IPO listing gains in the Indian market.

---

## Objective

To determine the relative predictive power of:

- Grey Market Premium (GMP)
- QIB Subscription
- HNI Subscription
- Retail Subscription
- Media Sentiment
- Issue Size

for forecasting IPO listing-day returns.

---

## Dataset

- **258 Indian Mainboard IPOs**
- **Period:** 2016–2025
- **Markets:** NSE & BSE
- Industries include Manufacturing, Finance, Pharmaceuticals, Technology, Consumer Goods and Infrastructure.

---

## Methodology

- Data Collection & Cleaning
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Multiple Linear Regression (OLS)
- Model Diagnostics
- Statistical Significance Testing

---

## Tools Used

- SPSS
- Microsoft Excel

---

## Key Findings

- Grey Market Premium (GMP) emerged as the strongest predictor of IPO listing gains.
- QIB subscription significantly improves prediction accuracy.
- HNI subscription has a positive but weaker impact.
- Retail subscription was not statistically significant after controlling for institutional demand.
- Media sentiment did not provide meaningful incremental predictive power.
- Issue size should be considered when interpreting subscription multiples.

---

## Business Impact

Instead of relying on a single market signal, investors should evaluate IPOs using a structured hierarchy of indicators.

Recommended evaluation order:

**GMP → QIB Subscription → HNI Subscription → Issue Size → Retail Subscription**

This framework helps investors distinguish genuine institutional demand from short-term market hype.
