# Business Intelligence Dashboards

## Overview

This project showcases interactive dashboards developed to monitor business performance, campaign effectiveness, operational KPIs, and executive decision-making.

---

## Dashboards Included

- Marketing Performance Dashboard
- CRM Funnel Dashboard
- Executive KPI Dashboard
- Campaign Performance Dashboard

---

## Tools Used

- Power BI
- Excel
- SQL

---

## Key Features

- Interactive Filters
- KPI Tracking
- Trend Analysis
- Conversion Funnel
- Executive Reporting

---

## Business Impact

These dashboards transformed raw operational data into actionable insights, enabling faster reporting and better strategic decision-making.
