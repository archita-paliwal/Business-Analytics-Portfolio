# Return-to-Origin (RTO) Analysis

## Business Problem

High Return-to-Origin (RTO) rates increase logistics costs, delay cash recovery, and reduce profitability for e-commerce businesses.

This project investigates shipment data to identify the primary drivers of RTO and recommend actions to reduce return rates.

---

## Objective

To analyze shipment behavior and identify factors contributing to Return-to-Origin.

---

## Dataset

- ~4,000 E-commerce Shipments

---

## Methodology

- Exploratory Data Analysis
- Segmentation Analysis
- KPI Reporting
- Business Analytics

---

## Tools Used

- Excel
- Python

---

## Key Findings

- Cash-on-Delivery orders experienced significantly higher RTO than prepaid orders.
- Nearly ₹9.69 lakh of blocked order value was identified.
- Customer payment behavior strongly influenced return probability.

---

## Business Impact

The findings support operational changes such as encouraging prepaid payments, improving customer verification, and optimizing order confirmation processes.
